# Сборка трех таплинков

Дизайн общий (template.html), ссылки и карточки площадок в build.py.

1. Склонировать рядом: taplink-tiktok, taplink-instagram, taplink-youtube.
2. Поправить PLATFORMS / CARDS в build.py.
3. `python3 taplink-tiktok/_build/build.py <папка, где лежат три репозитория>`
4. Закоммитить index.html в каждом репозитории.

Реестр ссылок: в материалах проекта «Лид-магниты и материалы», файл claude/таплинки-и-ссылки.md.
